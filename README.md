# RetailCRM to Supabase Sync & Dashboard 🚀

Тестовое задание на позицию AI Tools Specialist. Проект включает в себя автоматизацию обмена данными между RetailCRM и Supabase, систему Telegram-уведомлений и веб-дашборд.

## 🛠 Стек технологий
* **Python**: Основная логика синхронизации и бот.
* **Supabase (PostgreSQL)**: Облачное хранилище данных.
* **Vercel**: Хостинг веб-интерфейса.
* **Chart.js**: Визуализация статистики заказов.
* **Telegram Bot API**: Мгновенные уведомления о крупных сделках.

## 🤖 AI Workflow (Cursor + Gemini)

Проект разработан с активным использованием AI-инструментов. Основным рабочим окружением была IDE **Cursor**, а в качестве ассистента выступала модель **Gemini**.

### Как это помогло:
* **Генерация кода:** AI помог быстро выстроить архитектуру скрипта синхронизации, настроить работу с API и обработку данных.
* **Troubleshooting:** Когда при первом пуше в публичный доступ попали секреты (API-ключи), AI помог пошагово очистить историю репозитория через `git rm` и `force push`.
* **Deployment:** Ассистент подсказал, как правильно настроить Environment Variables в Vercel, чтобы дашборд корректно подключался к базе данных после публикации.

### Основные промпты:
1. *"Напиши Python скрипт для интеграции RetailCRM и Supabase. Нужно забирать заказы через API и сохранять их в Postgres, используя метод upsert для защиты от дублей."*
2. *"Добавь логику: если сумма заказа превышает 50 000 ₸, бот должен отправить сообщение в Telegram."*
3. *"Создай легкий HTML-дашборд на Chart.js, который подключается к Supabase и строит график продаж."*

## 🚀 Установка и запуск
1. Склонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Настройте файл `.env` (используйте `env.example` как шаблон).
4. Запустите скрипт: `python sync.py`.
